A make.fun entry for the **news-image-20261119** bounty: sum up 19 November's
world news in one image.

The entry is a colour vintage-newspaper front page — *The Daily Meridian* —
with a deep-red masthead and dateline, a lead story on the three-way summit
in Shenzhen, and five more stories in ruled columns below. Every word is
typeset programmatically and every picture is drawn in code with flat
newsprint colours; nothing in the image is generated by a model.

![The Daily Meridian front page](entry.png)

5. **UNHCR halts Malaysia registration** — refugee agency stopped registration

6. **GTA VI arrives after 13 years** — released at midnight worldwide, ending

## How it is built

- `render_image.py` — renders `entry.png` (1024×1024, under 1 MiB) with Pillow.
  Deterministic: fixed layout, no randomness, no timestamps, no network.
- `main.py` — the entry point. Standard library only; copies the held
  `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR` when set),
  byte-identically on every run.

## Reproduce it

```sh
python3 render_image.py   # rebuilds entry.png
python3 main.py           # copies it to /output/entry.png
```
